Forecasts Grand Theft Auto VI's launch-day Twitch concurrent viewers, hour by hour (hours 2–24 UTC), as log-scale quantile fans. The model learns the launch-day shape from past game launches shipped with the case: a per-hour regression on log(hour-1 viewers) and the NZ/AU pre-midnight wave peak, blended with a console-only median-ratio fan. Practice mean pinball loss 0.205 vs the house baseline's 0.387.

## Run it

```sh
mkdir -p out && MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=out python3 main.py
```
